# 资源管理系统 - 执行计划

**创建时间**：2026-01-26

## 任务上下文

### 目标
开发一个资源管理系统，用于管理NAS上的多平台软件资源（Mac/Windows/Android/Switch），支持目录扫描、分类展示、版本历史、拖拽上传、预览图管理。

### 技术栈
- **前端**：React 18 + TypeScript + Vite + Bun + shadcn/ui + Tailwind CSS
- **后端**：Python + FastAPI + uv + SQLAlchemy + SQLite
- **部署**：Docker Compose

### 核心功能
1. 扫描指定目录并按平台分类
2. 聚合页展示所有平台
3. 资源详情页显示版本历史
4. 拖拽上传资源文件
5. 手动上传预览图
6. 一键下载

### 阶段二：后端核心功能开发

#### 步骤 2.1：数据库模型设计
**文件**：`backend/app/models/database.py`
- 函数/类：`Base`, `engine`, `SessionLocal`
- 逻辑：配置 SQLAlchemy 数据库连接

**文件**：`backend/app/models/resource.py`
- 类：`Resource` (id, name, platform, category, description, cover_image, created_at, updated_at)
- 类：`Version` (id, resource_id, version, file_path, file_size, upload_date)
- 逻辑：ORM 模型定义，关系映射

#### 步骤 2.2：Pydantic Schema 定义
**文件**：`backend/app/schemas/resource.py`
- 类：`ResourceCreate`, `ResourceUpdate`, `ResourceResponse`
- 类：`VersionCreate`, `VersionResponse`
- 逻辑：请求/响应数据验证

#### 步骤 2.3：目录扫描服务
**文件**：`backend/app/services/scanner.py`
- 类：`DirectoryScanner`
- 方法：`scan_directory(base_path: str) -> List[Resource]`
- 方法：`detect_platform(filename: str) -> str`
- 方法：`extract_version(filename: str) -> str`
- 逻辑：递归扫描目录，解析文件名识别平台和版本

#### 步骤 2.4：文件管理服务
**文件**：`backend/app/services/file_manager.py`
- 类：`FileManager`
- 方法：`save_upload_file(upload_file, platform: str) -> str`
- 方法：`save_cover_image(upload_file, resource_id: int) -> str`
- 方法：`get_file_path(resource_id: int, version: str) -> str`
- 逻辑：处理文件上传、保存、路径管理

#### 步骤 2.5：API 路由 - 资源管理
**文件**：`backend/app/api/resources.py`
- 路由：`GET /api/v1/resources/` - 获取资源列表（支持平台/分类筛选）
- 路由：`POST /api/v1/resources/` - 创建资源
- 路由：`GET /api/v1/resources/{id}` - 获取资源详情（含版本历史）
- 路由：`PUT /api/v1/resources/{id}` - 更新资源
- 路由：`DELETE /api/v1/resources/{id}` - 删除资源
- 逻辑：CRUD 操作，数据库交互

#### 步骤 2.6：API 路由 - 上传与扫描
**文件**：`backend/app/api/upload.py`
- 路由：`POST /api/v1/upload/file` - 拖拽上传资源文件
- 路由：`POST /api/v1/upload/cover` - 上传预览图
- 逻辑：文件验证、保存、数据库记录

**文件**：`backend/app/api/scan.py`
- 路由：`POST /api/v1/scan/` - 触发目录扫描
- 逻辑：异步扫描，更新数据库

#### 步骤 2.7：API 路由 - 下载
**文件**：`backend/app/api/download.py`
- 路由：`GET /api/v1/download/{id}` - 下载指定版本
- 逻辑：文件流传输

#### 步骤 2.8：CORS 与中间件配置
**文件**：`backend/app/core/config.py`
- 类：`Settings` (API 配置、CORS 设置)
- 逻辑：环境变量管理

**文件**：`backend/app/main.py`
- 函数：`create_app()`

## 风险与注意事项

1. **文件路径处理**：跨平台路径兼容性（Windows/Linux）
2. **大文件上传**：分块上传或流式传输
3. **并发扫描**：避免重复扫描和资源竞争
4. **权限管理**：后续可添加用户认证
