界面示意 · 实际内容来自你的 NAS

Features

该有的都有，别的不加。

不是网盘，也不是应用商店。它只做一件事：把散落在磁盘里的安装包，整理成你愿意打开的样子。

一次拖入多个文件

批量上传队列会逐个处理，每个文件都有独立进度、失败重试和取消。同名文件自动提示，不会打断整批操作。

APK / DMG 深度解析

读取 APK 的 manifest 与资源表、DMG 里的 Info.plist 与 icns，自动补上应用名、包名、版本、最低系统、CPU 架构和图标。

目录即资源库

指向 NAS 上的任意目录，扫描一次即可入库。按 mtime 与大小做缓存，之后加新文件只解析新增部分，几秒完成。

任何地方都能打开

前端与 API 同源，一个端口走遍局域网与公网域名。飞牛等面板里直接点开，HTTPS 反代下也不会被跨域或混合内容拦住。

Parsing

文件名之外的
那些信息。

同一个应用的不同版本自动合并成一张卡片。点进去，看到的是真正有用的字段，而不是一串哈希。

  • 应用名 来自清单里的本地化名称
  • 包名 APK 的 package、DMG 的 Bundle ID
  • 版本 versionName / CFBundleShortVersionString
  • 系统要求 minSdk / 最低 macOS 版本
  • 架构 arm64、x86_64、universal
  • 图标 从资源表或 icns 还原

Quick start

四条命令，
跑起来。

一台装好 Docker 的 NAS 或小主机就够了。数据库用 SQLite，数据目录挂载在本地，升级只是重新构建镜像。

FastAPI React SQLite Docker androguard 7-Zip
terminal 
# 拉取代码
git clone https://github.com/zhuhaoxlj/ResourceManager.git
cd ResourceManager

# 配置资源目录与端口
cp .env.example .env

# 构建并启动
docker compose up -d --build
